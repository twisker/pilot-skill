# 隐私声明（匿名统计）

**中文** | [English](https://twisker.github.io/pilot-skill/en/privacy.html)

PILOT 内置一套**匿名使用统计**，用来回答一个问题：这个项目到底有没有人在用、哪些功能真的被用到。本页面完整说明它收集什么、不收集什么、数据存在哪里、以及如何一键关闭。原则只有一条：**统计只描述"发生了什么类型的事"，永远不携带"你说了什么、你是谁"。**

## 当前状态：已启用上报

自 v5.0（2026-09-24 项目转为完全免费）起，发行版的上报端点为**阿里云函数计算（FC）上的 PILOT 计数服务**，事件会离开你的机器。数据存放在**中国境内**（阿里云杭州地域）。本页描述的就是当前生效的完整契约。

## 收集什么

客户端（`tools/lib/telemetry.ts`）只生成下面这些内容：

| 数据 | 说明 |
|------|------|
| 匿名安装标识 `install_id` | 首次运行时在本机随机生成的 UUID（存于 `~/.pilot/telemetry.json`）。**唯一用途是去重**——同一个人多次上报只算一次安装。不含任何身份信息，不与账号、邮箱、设备指纹关联 |
| 事件计数（白名单**三种**） | `install`（安装）/ `trip_created`（创建行程）/ `export`（导出路书）。2026-09-24 项目转为完全免费后，原有的推荐类事件（`reco_impression` / `reco_dismissed` / `booking_link_shown`）已随商业化代码一并移除，**不再采集** |
| 目的地粗粒度 | `trip_created` 附带目的地字符串（城市/地区级，如"新疆"）与行程天数，仅此两项 |
| 导出格式 | `export` 附带格式名（pdf/xlsx/docx） |

白名单在代码层强制：白名单外的事件与字段**直接丢弃**，所有字符串一律截断到 200 字符——结构上排除了对话内容等大块文本混入的可能。服务端执行**同一份白名单**做二次过滤。

上报方式是 HTTPS POST 到计数端点，请求体里只有 `install_id` 与事件队列。任何网络请求都会让对方看到来源 IP，因此 IP 在服务端如何处理，单独说明如下。

## 服务端存什么

计数服务只落三张表的**聚合数据**，没有任何逐条的行为明细：

| 表 | 存的字段 | 用途 |
|------|------|------|
| `installs` | `sha256(install_id)` 的前 32 位（单向哈希，不可反推原值）、首次出现日、最近出现日 | 独立安装数、活跃度 |
| `counts` | 日期、事件名、当天发生次数 | 事件趋势。**不保留单条事件的时间戳** |
| `ip_guard` | 日期、`sha256(当日盐 + IP)` 的前 16 位、当天请求次数 | **仅用于防刷限流** |

关于 IP 的完整交代：

- **IP 原值从不落库**，也不写入任何日志；
- 「当日盐」= `sha256(根密钥 + 日期)`。根密钥只存在服务端环境变量里，绝不下发、绝不入库；**每天自动换盐**，所以同一个 IP 在不同日期会得到不同的哈希，无法从 `ip_guard` 表拼出某个 IP 的跨天轨迹；
- 如果服务端未配置根密钥，**连 IP 哈希都不记录**（此时不做限流）；
- 国家/地区码：仅在边缘节点提供该字段时记录；当前部署的阿里云 FC 不提供，因此该字段为空。

## 不收集什么

- **对话内容**：你和 PILOT 说的任何话、行程的具体内容、修改或拒绝的理由，一律不采集；
- **身份信息**：姓名、邮箱、账号、设备/浏览器指纹，一概没有；
- **精确位置**：不采集 GPS 或精确坐标，目的地只到城市/地区级字符串；
- **cookie 与登录态**：`~/.pilot/cookies/` 只在本机使用，绝不上传（见 [cookie 指南](https://twisker.github.io/pilot-skill/zh/guide-cookies.html)）；
- **IP 原值**：客户端上报不含 IP；服务端只保留上表所述的天级盐化哈希，且不用于计数、不与 `install_id` 关联。

## 为什么收集

只为一个目的：**知道有多少人在下载、安装、使用**，以及哪种导出格式常用——以此判断项目是否真的有人在用、力气该花在哪里。没有广告用途，不做用户画像，不出售，不与第三方共享。

## 如何关闭（任一方式即全局关闭）

```bash
# 方式一：环境变量（写进 shell 配置即永久生效）
export PILOT_TELEMETRY=off

# 方式二：把 ~/.pilot/telemetry.json 的 enabled 置 false
```

关闭后所有统计调用自动变为空操作：不生成事件、不写队列、不上报。

**本地留了哪些文件**：`~/.pilot/telemetry.json`（`install_id` 与开关状态）、`~/.pilot/telemetry-queue.jsonl`（尚未发送的事件队列，上限 1000 条）。这两个文件随时可以打开查看、直接删除。

## 删除已经上报的数据

你的 `install_id` 就在本机 `~/.pilot/telemetry.json` 里。带上它到 [GitHub Issues](https://github.com/twisker/pilot-skill/issues) 提一条请求，我们会删除对应的安装记录。除此之外的存储内容只有天级聚合计数（`counts`）与限流用的当日 IP 哈希（`ip_guard`），都不含任何可定位到个人的标识。

## 数据存放位置

阿里云函数计算（FC）+ 阿里云 RDS PostgreSQL，地域为**中国杭州（cn-hangzhou）**。数据不出境。
